# Контрольна робота №2 — Фільтрація даних та інтеграційне тестування Web API на ASP.NET Core

## Тема: Спортзал (Сутність: `Exercise`)

## Мета:

Розширити Web API, створений у контрольній роботі 1, фільтрацією записів за полями сутності та покрити API інтеграційними тестами, застосувавши підходи, розглянуті на заняттях: побудова запиту через IQueryable з необов'язковими умовами, запуск застосунку в пам'яті через WebApplicationFactory , ізольована база даних PostgreSQL у Docker-контейнері (Testcontainers), спільна тестова інфраструктура, окремий проєкт із тестовими даними, підготовка та очищення даних для кожного тесту, перевірка як HTTP-відповіді, так і стану бази даних.

### Поля сутності `Exercise`:

- `Id` (`ExerciseId`) — типізований ідентифікатор (GUID)
- `Name` (`string`) — назва вправи (унікальне поле)
- `CaloriesPerHour` (`decimal`) — кількість спалюваних калорій за годину (число)
- `RequiresEquipment` (`bool`) — чи потрібне обладнання (логічне значення)
- `MuscleGroup` (`MuscleGroup`) — група м'язів (`Chest`, `Back`, `Legs`, `Arms`, `Shoulders`) (перелік / enum)
- `CreatedAt` (`DateTime`) — дата й час створення запису (UTC)
