# Мета роботи:

## Опанувати WebApplicationFactory<TEntryPoint> : запуск застосунку всередині тестового процесу та підміну його залежностей.

## Запускати для тестів справжній PostgreSQL у Docker-контейнері за допомогою Testcontainers.

## Зрозуміти життєвий цикл тестів у xUnit: спільні ресурси (fixtures),підготовка та очищення даних.
